# Smart Campus Information System

A Python mini project developed for Python Programming Laboratory.

## Features
- Student Registration
- Grade Evaluation
- Course Enrollment
- Record Management
- Sorting and Searching
- Fee Calculation
- File Handling
- Directory Scanning
- Performance Analytics using NumPy, Pandas, and Matplotlib

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the program:

python smart_campus.py
